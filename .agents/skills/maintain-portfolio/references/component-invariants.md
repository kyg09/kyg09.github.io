# 기능별 유지 조건

현재 수정하는 기능의 항목만 읽는다. 여기의 기능별 검증은 해당 동작을 바꿀 때 적용하며, 문구·색상·간격 수정에 전체 동작 검증을 확장하지 않는다. 실제 동작 규칙이 바뀔 때만 이 문서를 갱신한다. 색상·투명도·간격의 실제 값은 CSS를 기준으로 관리하며 단순 수치 수정에 문서를 함께 고치지 않는다.

- 우측 섹션 목차는 `SectionNavigation`의 독립 effect로 관리하고 해제 시 이벤트·observer·RAF를 정리한다. 소개 항목의 이름은 `Frontend Developer`로 고정하고 나머지는 실제 주요 h2에서 읽으며 본문 순서를 유지한다. 1280px 이상에서만 sticky로 보이며 모달·인트로 중에는 숨긴다. 비선택 링크는 은은하게, hover·focus-within은 선명하게 표시하며 기존 전환 타이밍을 유지한다. 선택 링크와 표시선은 섹션 제목의 공통 `--color-section-title`을 사용하고 선택 상태가 구별되게 표시한다. 문서 위치는 캐시한 좌표와 같은 상단 오프셋을 기준으로 추적하고, 표시선은 링크의 실측 위치·높이를 사용한다. 클릭 이동 중 사용자 입력이 오면 잠금을 풀고 실제 위치 추적을 재개한다. 해시 직접 진입은 기존 pathname 섹션 이동 후에도 유효해야 하며, 수동 스크롤로 방문 기록을 추가하지 않는다. 캐러셀의 중앙 위치와 본문 폭은 유지하고 목차가 쓰는 우측 공간은 카드·갤러리가 침범하지 않게 한다.

- 인트로는 벽 오프닝 2.95초, 로고 표시 5초, 헤더 이동 1.05초로 이어진다. 로고 SVG의 잉크는 로드 2초 뒤 시작하며 로드 완료로 타이머를 재시작하지 않는다. 검은 벽을 왼쪽 끝에서 움직여 로고와 SKIP을 점진적으로 드러낸다. 벽과 캐릭터는 같은 타임라인을 쓰고 프레임별 손 접촉점과 발 기준선을 확인한다. 벽이 SKIP의 버튼 영역을 지나면 입력을 허용하고 헤더 이동과 동시에 숨긴다. SKIP에는 `profile-accent-strokes` 빨간 SVG를 사용한다. 키보드 SKIP·Escape·새로고침·모션 줄이기·벽 이미지 로드 실패를 확인한다.

- 벽을 처음 미는 0.32초에는 07·08 그림의 뒷발 접지점을 고정하고 세 중간 자세를 보간한다. 이후 기존 걸음으로 넘어갈 때 벽 속도와 캐릭터 위치가 이어지도록 맞춘다.

- Projects는 DDOGA 스토어 대표 카드와 나머지 작업의 보조 캐러셀로 구성한다. 보조 캐러셀은 620px 본문 레이아웃 경계 안에서 실제 레일 폭을 기준으로 중앙 정렬하고 양끝 60px 블러는 카드 행만 덮는다. 스크롤 영역 위 1.5rem·아래 3rem 여유와 대응 음수 마진을 유지하고, 간격을 수정할 때 이동 거리에도 같은 값을 쓴다. Engineering Notes는 데스크톱 두 열·모바일 한 열의 정적 그리드이며 캐러셀 페이지 점을 생성하지 않는다.

- Experience는 기존 본문 폭의 2열 확장형으로 왼쪽 8rem에 영문 회사명·기간, 오른쪽에 회사 요약과 프로젝트별 역할을 표시한다. 프로젝트와 회사 사이의 여백을 구분하고 좁은 화면에서 한 열로 쌓는다. 구분선은 회사 사이에만 둔다. 프로젝트 링크는 공통 ExperienceProjectLink로 기존 상세 주소·data-controls와 손그림 밑줄을 유지하며 한국어 문구와 영어 사전을 함께 수정한다.

- Engineering Notes에서 미디어 갤러리로 이어지는 상단 여백은 `#playground`에서 조정한다.

- Engineering Notes 상세 모달은 짧은 콘텐츠를 세로 중앙에 배치하고 긴 글은 첫 문단부터 스크롤할 수 있게 한다. 정렬은 `.thought` 범위에 적용한다.

- 고정 상세 패널의 래퍼인 `.project-list`와 `.thought-list`는 섹션 등장 애니메이션의 opacity·transform 대상에서 제외한다. 모바일 Safari에서는 스크롤 직후 25ms 안에 카드를 눌러도 패널이 화면 전체를 채우는지 확인한다. 등장 전환이 끝난 뒤만 검사하지 않는다.

- 프로젝트·노트 상세는 마우스 휠·트랙패드·터치 스크롤로 닫지 않는다. 스크롤은 본문과 읽기 진행 표시만 바꾼다. 닫기 버튼·Escape·브라우저 뒤로가기는 유지하고, 짧은 글과 긴 글의 끝에서 반복 스크롤한 뒤에도 열림이 유지되는지 검증한다.

- Engineering Notes 카드는 주제별 흑백 손그림 도식과 요약을 표시하고 제목의 핵심 구절에만 노란 형광펜을 적용한다. 도형은 기존 `hand-drawn` 필터와 `--hand-line` 마스크를 재사용하고, 작은 글자는 필터 밖에 둔다. 도식은 `NoteGraphic`, 요약과 강조 구절은 노트 데이터에서 관리한다.

- Projects 보조 캐러셀은 원본 카드의 `translate` 위치를 재배치하는 무한 루프다. 시각용 사본에는 상세 ID·data-controls·키보드 탐색 지점을 중복하지 않으며 영상은 포스터만 사용한다. 자동 이동은 `data-autoplay`가 있는 경우에만 활성화하며 기본은 꺼 둔다. 상세 이전·다음 순서는 대표 카드·보조 캐러셀의 모든 원본 프로젝트와 Notes 그리드 전체를 포함한다. 캐러셀의 양방향 경계·페이지 점 동기화·비활성 카드 탭 제외와, 대표·그리드 카드의 키보드 열기·닫기·복귀를 확인한다.

- 콘솔 이스터에그는 문서 진입 시 한 번만 출력한다. 개발 모드 반복 마운트나 같은 문서의 언어·상세 주소 전환에서 중복 출력하지 않고, 인사말의 한·영 사전을 함께 관리한다.

- What I Do는 첫 항목을 기본으로 펼친다. 초기 마크업의 `is-open`, `aria-expanded`, `inert`와 런타임의 열린 항목 상태를 일치시키고, 첫 항목 접기·재열기와 다른 항목 전환을 검증한다.

- 푸터 마지막의 저작권 문구는 모든 언어에서 `© 2026 Kim Young Geun. All rights reserved.`로 표시한다. 제작 연도 2026년을 고정하고 이메일과 같은 글자 크기를 사용한다. 문구의 아래쪽을 페이지 맨 아래에서 정확히 50px 위에 배치하며, main의 추가 하단 패딩이 간격에 더해지지 않게 한다.

- 이력서를 마우스·터치로 닫으면 시작 버튼의 포커스와 이력서 준비 상태를 해제한다. 키보드로 닫을 때는 시작 버튼으로 포커스를 돌려 다시 열 수 있도록 유지한다.

- 상세·이력서의 하단 닫기 버튼은 공통 `CloseProgressRing`과 `initCloseProgress`로 읽기 진행을 0~100% 표시한다. 재열기 시 0%로 초기화하고 언어·본문 높이·화면 크기가 바뀌면 다시 계산한다. 모션 감소에서는 링 전환을 생략하며, 끝에서 더 스크롤해도 모달을 닫지 않는다.

- 이력서 모달의 섹션 소제목에는 상단 이름과 같은 글자색을 쓰고, 회사명·프로젝트명·업무 제목에는 볼드를 적용한다. 회사명은 프로젝트명보다 크게 표시하고, 조아실버케어는 헥톤프로젝트 하위에 배치한다. SKILL은 `StackBadges`로 기술 아이콘을 대표 색상으로 표시하며 하나의 목록으로 배치한다. 경력 제목을 나눠 렌더링할 때는 한·영 번역 키를 제목과 설명에 각각 맞춘다.

- 카드의 떠다니는 제목·프로젝트 미리보기·기울기·들림·도식 hover 모션은 769px 이상이며 hover 가능한 정밀 포인터의 실제 마우스 입력에서만 실행한다. 모바일의 터치·펜·sticky hover에서는 표시하지 않으며, 환경 변경 시 열린 장식과 rAF를 정리한다. 실제 카드 선택·캐러셀 이동·상세 열기·닫기와 키보드 포커스 표시는 유지한다. 카드 외 터치 피드백은 기존 `initTouchFeedback`의 `.is-touch-active`를 사용하고 해제·취소·드래그·스크롤·화면 이탈 시 정리한다.

- 기술 스택 타일은 터치·펜으로 누르는 동안 브랜드 색상을 표시하고, 손을 떼거나 입력이 취소되면 해제한다. 여러 색상의 아이콘 내부 조각도 함께 전환하고 기존 hover·키보드 포커스 효과를 유지한다.

- 손그림 밑줄은 마우스에서는 hover, 터치에서는 누르는 동안의 active 상태로 강조한다. 터치 후 hover 강조가 남지 않도록 hover 규칙은 정밀 포인터 환경으로 제한하고, 링크·버튼의 키보드 focus-visible 강조를 유지한다.

- 본문 섹션은 최초 노출 시 콘텐츠가 20px 위로 이동하며 650ms 동안 나타난다. 소개의 기존 등장 효과, 상세 패널의 고정 위치, 직접 접속한 섹션의 즉시 표시를 유지하고 모션 줄이기에서는 섹션 효과를 생략한다.

- 모바일(768px 이하)의 플로팅 이력서 버튼은 아이콘만 표시하고 TOP 버튼과 같은 2.75rem 크기를 유지한다. 숨긴 버튼 문구는 스크린 리더가 읽을 수 있어야 한다.

- 공개 화면에서 쓰는 파일은 `public/`의 용도별 위치에 둔다. 프로젝트 카드뿐 아니라 직접 접속 가능한 상세 페이지, 영상 포스터, `srcSet`, SVG 내부 참조를 확인한 뒤 미사용 에셋을 정리한다.

- Projects는 기존 영상을 상단에 유지하고 서비스명·기간·요약·짧은 담당 영역을 표시한다. 카드 서비스명은 preview.title, 상세 구조는 caseStudy에서 관리한다. 상세는 Overview·My Role·Key Flow·Implementation·SKILL 순서로 표시하고, 업무 흐름은 ProjectFlow의 순서 목록으로 표현한다. 영상 원본과 상세 URL을 유지하며 대표 카드와 중앙 보조 카드는 화면에 보일 때만 재생한다. 모달 스킬 아이콘은 컬러로 표시한다.

- 하단 미디어 갤러리는 기존 20개 위치·비율·스크롤 상호작용을 유지하고 gallery-items의 영상 6개·기능 확대 이미지 14개를 표시한다. 이미지는 기존 영상에서 extract-project-stills.swift로 추출한다. 이미지 선택은 이미지로, 영상 선택은 영상으로 확대하고, 닫기·Escape 후 포커스 복구와 재선택을 확인한다. 미디어 설명·접근성 이름도 한영 전환에 맞춰 갱신한다.


- UI Playground의 장바구니는 DDOGA의 선택·옵션 묶음·수량·재고·지원금 전환 패턴을 가상 데이터로 재구성한 독립 예제다. 실제 로그인·공단 조회·주문 API는 사용하지 않는다. 수급자별 프로필·품목별 급여 구매 가능 수량·예상 차감액을 표시하고 프로필별 장바구니 버킷을 독립 보관한다. 복지용구의 지원금 사용 OFF는 일반가 구매이며 일반케어상품으로 분류를 바꾸지 않는다. 전체/묶음 선택, 삭제·되돌리기·빈 상태 복원, 품목 수량→지원금 금액 순서의 주문 조건 확인과 미리보기 복귀를 제공한다. 지원금 부족으로 구매 유형을 자동 변경하지 않고 사용자가 직접 토글로 바꾼다. 재고가 기존 수량보다 적더라도 감소는 한 단계씩 허용하고 증가 조작이 수량을 줄이지 않게 한다. 계산 상태는 cart-playground 모델에서 파생하고 동일 선택을 건수·금액에 사용한다. 키보드로 최초 조작부터 복구 후 재조작까지 확인한다.

- 장바구니와 Beyond Code는 usePortfolioLocale로 html.lang을 구독한다. data-localized-skip 내부의 텍스트·속성·링크는 기존 DOM 번역기가 직접 바꾸지 않으며 언어 전환 중 장바구니 상태를 보존한다. Beyond Code는 사용자가 제공한 독서·이북리더기·클래식 음악·차·웨이트 취향만 표시한다.

- 하단 스크롤 미디어 갤러리의 MediaWall import와 렌더링은 주석 처리한 상태로 유지한다. 관련 코드·20개 배치 데이터·미디어 에셋을 삭제하지 않고, 사용자 요청 없이 다시 노출하지 않는다.

- UI Playground의 네 탭은 장바구니·상품 옵션·시설 필터·주문 입력 예제를 표시하며 방향키/Home/End와 roving tabIndex를 지원한다. 비활성 패널은 hidden/inert로 포커스에서 제외하면서 컴포넌트 상태를 보존한다. 필터는 편집 중 조건과 적용 조건을 분리하고 취소 시 기존 결과를 유지한다. 상품 옵션은 상위 선택이 바뀌면 하위 선택만 초기화하고, 같은 옵션은 수량으로 병합하며 기존 담긴 수량을 포함해 재고를 검증한다. 삭제·되돌리기와 확인 후 수정을 제공한다. 주문 입력은 가상 고객·신청인·배송지·주문 경로의 의존 조건을 반영하고 오류 필드 포커스, 요약 후 수정·초기화를 제공한다. 실서비스 API를 호출하지 않는다.

- Beyond Code는 네 오브제를 선반에 배치하고 기본 Reading에서 시작한다. 실제 버튼의 aria-pressed로 현재 선택을 표시하고 Enter·Space로 소개를 바꾸며 언어 전환 중 선택을 보존한다. 오브제 모션은 .can-hover의 hover·focus-visible·공통 .is-touch-active에서만 한 번 재생하고 초기 자동 재생·무한 반복을 하지 않는다. 모션 감소 설정에서는 스트로크 드로잉·이동·회전을 생략한다. 작은 화면은 두 열로 배치하며 기존 섹션 주소·본문 폭을 유지한다.

- 소개의 MarkerText는 공식 Kokonut UI 원본의 SVG 펜 마스크·도형·타이밍을 유지한다. 원래 이름 밑줄과 빨간 포인트는 변경하지 않는다. 기본 자동 재생 없이 HeroMarkerText의 hover·공통 누름 상태로만 show를 켜며, 언어 교체·단어 분리·폰트·줄바꿈 뒤 SVG 좌표를 재측정한다. 영문으로 바뀐 문장의 마침표 앞 공백을 남기지 않는다. 원본 MIT 고지와 출처를 보존한다.
- 푸터는 캐릭터가 실제 화면에 들어온 뒤 한 번 축소·페이드하고 정해진 프로필 Q&A 세 개를 누적한다. 캐릭터와 대화는 고정 슬롯을 공유해 로고·이메일·저작권 위치를 재생 중 유지한다. 이전 답변이 끝난 뒤 새 질문이 아래에 나타나고 기존 대화는 위로 쌓인다. 실제 스크롤 영역은 만들지 않는다. 말풍선 폭과 이동은 실제 단어·요소 좌표로 계산하며 질문·답변의 글자 크기를 통일한다. 내용은 소개·경력·취미에 근거하고 Engineering Notes를 반복하지 않는다. 기존 will-sign 마스크·이동과 중복 적용하지 않는다. 스프링은 Streaming reply 원본 stream.js 수치·4회 서브스텝을 사용하고 매 프레임 React 렌더링·레이아웃 측정을 하지 않는다. 위로 스크롤해 대화 영역을 벗어나면 시간·spring 속도·답변·접근성 안내를 함께 초기화하고 캐릭터를 복원한다. 실제 캐릭터가 다시 보이면 처음부터 재생한다. 버튼은 표시하지 않는다. 탭 숨김과 언어 전환은 진행을 보존하며, 모션 감소 즉시 표시와 완성 답변 단위 접근성 안내를 제공한다.
