# UI Playground — 가상 장바구니 구성

포트폴리오에서 구매 조건과 주문 전 확인 흐름을 체험할 수 있도록 만든 독립적인 가상 장바구니다. 이름·프로필·상품 가격·잔여금·구매 가능 수량은 체험용 값이며 실제 제도나 개인의 급여 자격을 안내하지 않는다.

구현은 [순수 모델](../src/lib/cart-playground.ts)과 [체험 UI](../src/components/playground/CartPlayground.tsx)로 나눈다. 아래 내용은 이 저장소의 데모 동작을 설명한다.

## 프로필별 구매 조건

`CartProfile`은 본인부담률·잔여 지원금·적용기간·시설 입소 여부와 품목별 구매 가능 수량인 `categoryLimits`를 구분한다. 상품이 급여 가능하다는 속성과 선택한 프로필이 구매할 수 있는 수량은 별도로 판단한다.

A/B/C/일반 고객은 서로 다른 가상 조건을 가진다. `CartPlayground`의 `profileCarts`는 프로필별 선택·수량·급여 설정·삭제 복구 기록을 보존하므로 프로필을 바꾼 뒤 돌아와도 이전 조작을 이어갈 수 있다.

## 상품 분류와 구매 방식

`eligible`은 상품의 급여 가능 속성, `useBenefit`은 사용자가 고른 구매 방식이다. 지원금 사용을 꺼도 상품의 분류는 유지하며 일반가 결제액으로 계산한다.

`getCartGroups`는 급여 적용 옵션을 각각 표시하고 같은 상품의 일반 옵션은 한 카드로 묶는다. 각 그룹의 전체 선택·부분 선택 상태는 선택 가능한 옵션을 기준으로 계산한다.

## 주문 전 검증 순서

`validateCart`는 선택한 항목의 유무와 재고를 확인한 다음 급여 적용 조건을 검사한다. 선택된 급여 적용 옵션의 수량을 품목별로 합산하고, 허용 수량을 초과하는지 확인한 뒤 예상 차감액과 잔여금을 비교한다. 예상 차감액이 잔액과 같으면 통과하고 초과하면 안내를 표시한다.

`getBenefitIssue`는 알림에 필요한 품목 분류, 허용·선택·초과 수량 또는 잔액·예상 차감액·초과 금액을 반환한다. 데모는 선택한 항목 전체를 확인하는 흐름이며 개별 카드 주문은 포함하지 않는다.

## 적용 금액과 고객 결제액

지원금 차감 예상액과 고객의 본인부담금은 구분한다. `benefitAmount`는 급여 적용 구매 상품의 전체 가격이며 고객 부담은 가상 본인부담률로 계산한다. 결제 요약은 급여 본인부담금·복지용구 일반가·일반케어 금액을 나눠 표시한다.

## 사용자가 바꾸고 다시 시도

부족액이 발생해도 급여 설정을 자동으로 바꾸지 않는다. 사용자가 알림을 닫고 급여 설정·수량·선택을 직접 수정한 뒤 다시 검증한다. 삭제 취소는 삭제된 항목만 복구해 다른 항목의 후속 편집을 유지한다.

실제 조회·주문 등록·결제 API에는 연결하지 않는다. 적용기간은 가상 값이며 대여 일수 안분, 배송·할인 정산은 구매 예제의 범위에 포함하지 않는다. 가상 조건과 복구 동작은 [모델 검사 스크립트](../scripts/check-cart-playground.mjs)로 확인한다.
