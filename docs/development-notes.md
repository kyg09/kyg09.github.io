# 개발·마이그레이션 기록

## 구현에 사용한 기술과 도구

| 기술·도구 | 사용한 작업 |
| --- | --- |
| Next.js 16.2.6 App Router, React 19.2.6 | 한 페이지에 포트폴리오 본문과 상세 패널을 구성하고 한국어·영어 상세 주소를 빌드에서 미리 생성 |
| TypeScript 5.9.3 | 프로젝트·노트·기술 데이터와 공통 컴포넌트의 props 타입 정의 및 검사 |
| Tailwind CSS 4.2.1, PostCSS | 공통 레이아웃 유틸리티를 빌드하고 기존 색상·간격·폰트 및 키프레임과 결합 |
| JavaScript, 브라우저 API | 기존 인트로 타이머 및 로고 이동, 한·영 전환, 갤러리, 모달, 스크롤 상태와 브라우저 기록을 기능별 모듈로 이전 |
| Blossom Carousel | Projects와 Engineering Notes의 가로 카드 이동. 배포에 쓰는 스크립트와 CSS는 `public/assets/vendor/blossom-carousel/`에 포함 |
| Node.js 24, npm | 의존성 설치 및 잠금, Next.js 개발 서버와 배포 빌드 |
| 기존 Vite 포트폴리오 | Next.js 전환 전 화면과 미디어의 비교 기준 |
| Codex, Python, Prettier | HTML을 JSX로 옮기고 반복 구조를 공통 컴포넌트로 정리. 경로와 서식을 점검하는 작업에 사용 |
| Playwright CLI와 Chrome | 데스크톱·모바일 배치 비교, 키보드 재조작, 상세 주소와 영상 재생, 콘솔 오류 확인 |

Python, Prettier, Playwright CLI는 마이그레이션과 검증에 사용한 도구입니다. 포트폴리오를 실행하는 데 필요한 패키지와 버전은 `package.json`과 `package-lock.json`에서 확인할 수 있습니다.

## 전환 과정

1. 기존 화면에서 섹션, 모달, 데이터, 미디어 주소와 한·영 사전의 연결을 확인했습니다.
2. 프로젝트와 노트 목록을 공통 카드, 상세 패널, 영상 컴포넌트로 구성했습니다. 로고, 이력서 기간 표시와 기술 배지도 재사용하도록 분리했습니다.
3. Vite 페이지에 연결돼 있던 인터랙션을 기능별 모듈로 옮기고, 기존 요소의 상태와 직접 접속 주소를 연결했습니다.
4. 레이아웃에는 Tailwind 유틸리티를 사용하고 개별 모션과 테마 변수는 CSS에 정리했습니다. 캐러셀의 기본 규칙과 포트폴리오 규칙의 우선순위를 지정해 기존 카드 크기와 정렬이 재현되도록 했습니다.

## 검증한 흐름

- 데스크톱과 모바일에서 카드 목록과 SKILL 배치, 협업 툴의 위치와 툴팁 확인
- 인트로 자동 전환, 키보드로 건너뛰기, 새로고침, 24시간 숨기기 확인
- 아코디언 열기·항목 전환·닫기·다시 열기와 좁은 화면에서 설명 높이 확인
- 한·영 전환, 프로젝트와 Engineering Notes 직접 접속, 이전·다음, 브라우저 뒤로 가기 확인
- 이력서와 미디어 확대, 실제 영상 재생, 닫은 뒤 재선택 확인
- 타입 검사, 배포 빌드, 동작 검증 중 브라우저 콘솔 확인

## 에셋 감사

2026-11-16에 공개 파일 156개의 경로를 비교했습니다. 소스에서 사용하는 59개가 모두 존재했습니다. 같은 내용의 파일을 해시로 비교해 중복도 확인했습니다. 사용처가 없는 레퍼런스 97개는 `reference-assets/`에 기존 경로 구조대로 보관했습니다.

직접 주소로 열 수 있는 `/projects/joa-silvercare`와 `/projects/hecton-project`는 목록과 별개로 `public/assets/projects/`의 미디어를 사용합니다. 갤러리 타일은 `public/assets/portfolio-concepts/`의 카드 영상과 포스터를 재사용합니다. 프로젝트 실행과 검증에서는 이전에 완성된 MP4·JPG를 사용했으며, 해당 미디어의 제작 도구와 설정은 현재 소스에 기록돼 있지 않습니다.

## 파비콘과 공유 미리보기

첨부한 ICO와 SVG를 원본 그대로 반영하고 바뀐 파일의 해시를 파비콘 주소에 붙였습니다. 공유 카드는 기존 워드마크, 프로필 캐릭터, 본문 글꼴을 사용해 Playwright에서 1200×630 PNG로 렌더링했습니다. App Router가 주소의 언어에 맞는 Open Graph와 X 카드 메타데이터를 렌더링합니다.

## 레퍼런스 자료 제거

개인 소개 레퍼런스 패널과 전용 런타임·스타일, `public/assets/personal/`, `public/assets/projects/tribehouse/`, `public/assets/projects/smalltribe/`, 로컬 `reference-assets/` 보관 폴더를 삭제했습니다. 회사 상세 주소와 실제 경력 문구는 유지하고 레퍼런스 미디어만 제거했습니다. 위 보관 기록은 이전 작업 이력입니다.

## 미사용 파일 점검

Next.js 진입점부터 소스 41개의 import 연결을 확인했으며 미사용 소스 파일은 없었습니다. 사용하지 않는 ABC Diatype 4종, KP Duo Serif Display 2종, GT Sectra 1종과 대응 CSS 선언을 제거했습니다. 현재 기본 폰트인 ABC Areal과 대체 폰트 KP Duo Sans는 유지했습니다.
